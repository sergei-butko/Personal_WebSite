A batch code is a manufacturing reference. It exists so that a factory can trace
a filling run, not so that a collector can date a bottle. Everything we get out
of it is a side effect, and the decoder sites that turn four characters into a
confident calendar date are working from crowdsourced correlation, not from
anything a house published.

That does not make them useless. It makes them a hypothesis.

## What is actually in there

Across most houses, a code carries some subset of:

1. **A year reference** — usually one character, usually cyclic. A single digit
   repeats every ten years, so `4` is 2014 or 2004 or 1994, and only context
   tells you which.
2. **A period marker** — month, quarter, or an internal production window that
   maps to no calendar unit at all.
3. **A sequence number** — which run within that period. Carries no date
   information and is the part people most often over-read.
4. **A line or site marker** — which factory or filling line. Sometimes the most
   useful character in the code, because a line that opened in a known year puts
   a floor under the date.

## The cyclic-digit problem

This is the failure mode that produces most wrong datings:

```text
Code:  4501
       ^
       └── year reference "4"

Candidates:  1994  2004  2014  2024
Eliminated by: fragrance launch year (2010) → 1994, 2004 out
Eliminated by: cap design change (2019)     → 2024 out
Remaining:   2014
```

The digit alone gave four answers. The launch year and a physical detail of the
bottle gave one. **The code narrows; the bottle decides.**

## Physical tells that beat the code

When the code is ambiguous or absent, the packaging usually is not:

- **Cellophane seam and fold.** Houses change wrapping suppliers, and the seam
  moves when they do.
- **Barcode length and prefix.** A 13-digit EAN on a bottle that should predate
  its adoption is a strong forgery signal.
- **Ingredient list.** IFRA restrictions have hard dates. A list that names a
  material at a concentration restricted years earlier is either old stock or
  not what it claims to be.
- **Cap fit and knurling.** Cheap to reproduce badly, and the detail counterfeit
  runs get wrong most often.

<Note>
  The ingredient list is the one that most often settles an argument, because it
  is regulatory rather than aesthetic. Houses change caps when they feel like it;
  they change ingredient lists when they are made to.
</Note>

## Houses you cannot date this way

Some codes are genuinely opaque:

| House pattern | Why it fails |
| --- | --- |
| Pure sequence, no year field | Nothing in the code correlates with time |
| Re-used codes across SKUs | The same string appears years apart |
| Contract-filled niche lines | Code belongs to the filler, not the house |
| Codes printed on the box only | Gone the moment the box is |

For these, provenance is the only evidence: a receipt, a photograph with a
timestamp, or a seller you already trust. Nothing about the bottle will tell you.

## The honest workflow

1. Read the code off the **bottle**, not the box.
2. Generate the full candidate set, not the first plausible answer.
3. Eliminate with launch year, packaging, and ingredient list.
4. If more than one candidate survives, say so.

Step four is the one nobody does, and it is the only one that separates dating a
bottle from telling a story about it.
